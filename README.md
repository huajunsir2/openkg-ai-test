# 3D 贪食蛇 · Snake 3D

一个使用 [Three.js](https://threejs.org/) 编写的纯前端 3D 贪食蛇游戏。蛇头会显示一张可由你自行上传的头像（默认头像为占位图，避免侵犯肖像权）。打开 `index.html` 就能玩。

![preview](https://placehold.co/800x420/0a0d1c/7c8cff?text=Snake+3D)

## 特性

- 🧊 **3D 场景**：基于 Three.js 的真实灯光、阴影、辉光氛围
- 🖼️ **可自定义蛇头头像**：默认是“王一博”文字占位头像，点击右侧「上传头像」可换成任意人脸图片（推荐正方形）
- 🎮 **键盘 / 触屏操控**：方向键 / WASD / 触屏滑动均可
- 🌀 **穿墙模式**：勾选后蛇可以从一侧穿到另一侧
- 🔧 **可调速度与棋盘大小**：15×15 ~ 30×30，速度无级调节
- 🏆 **本地最高分记录**：使用 `localStorage` 保存
- 📱 **响应式布局**：移动端自动切换为竖向布局

## 关于「王一博头像」

由于直接打包真人明星照片会涉及肖像权 / 版权问题，本项目默认提供的是一张文字 + 渐变背景的占位头像。如果你想看到真正的王一博头像作为蛇头，请：

1. 自行准备一张你拥有合法使用权的图片（例如你保存的官方海报、自己制作的同人插画、或自己拍摄的照片）
2. 在右侧面板点击 **上传头像** 选择该图片
3. 蛇头的贴图就会立刻替换为你上传的图

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 向前 |
| `S` / `↓` | 向后 |
| `A` / `←` | 向左 |
| `D` / `→` | 向右 |
| `Space` | 暂停 / 继续 |
| `R` | 重新开始 |
| 触屏滑动 | 改变方向 |

## 本地运行

由于使用了 ES Module 与 importmap，需要通过 HTTP(S) 打开（不要直接 `file://` 双击）。任何静态服务器都行：

```bash
# Python 3
python3 -m http.server 8080

# 或 Node
npx serve .
```

然后打开 <http://localhost:8080>。
