# OpenKG 新网站

这是一个为 OpenKG 构建的静态官网模板，开箱即可本地预览与二次开发。

## 页面结构

- 顶部导航（桌面端/移动端）
- Hero 首屏（平台定位 + 关键数据）
- 平台介绍
- 核心能力
- 应用场景
- 资源中心
- 社区加入表单
- 页脚

## 功能特性

- 响应式布局，适配手机与桌面
- 深色模式切换（本地持久化）
- 移动端折叠菜单
- 订阅表单交互反馈

## 本地运行

这是纯静态站点，无需安装依赖。直接打开 `index.html` 即可。

如需本地 HTTP 预览，可使用：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
